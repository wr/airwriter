# Printers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AirWriter offers, over AirPrint and to old Macs, exactly the printers a person has, found or told, with a Printers section, printers in first-run setup, and existing boards unchanged.

**Architecture:** A pure-C printer list (`components/printers/printers_core.c`, host-tested) owns records, naming, identity, sharing, notices, migration and what old Macs are offered. A firmware glue (`printers.c`) persists it in NVS, feeds it what the port and AppleTalk find, and drives `ipp_server` (one slot per shared record), the AppleTalk links (one NBP registration per offered printer, plus an AirWriter marker) and the page. AppleTalk printers generalise W-1082's single LaserWriter; a PAP relay bridges a Mac on one link to a printer on another.

**Tech Stack:** ESP-IDF 5.5.1 C, FreeRTOS, esp-mdns; host tests in `tools/rip` (cc, Makefile); the page in `tools/webui` (HTML/JS, `mkheader.py`, `preview.py`); Python `etpeer.py` fakes; Ghostscript for PostScript checks.

**Spec:** `docs/superpowers/specs/2026-10-23-printers-design.md` (W-1088)

## Global Constraints

- No phantom printer: AirPrint advertises only records with `shared` on; old Macs are offered every identified record AirWriter can carry, shared or not.
- At most 4 records shared over AirPrint (1 on the port, 3 on AppleTalk); more are listed, not offered.
- Names come from the printer: an AppleTalk printer's NBP name; a port printer's model ("ImageWriter II", "ImageWriter LQ", "ImageWriter"); duplicates get " 2", " 3"; never "ImageWriter II" by default for a board with no ImageWriter.
- A record's `uuid` never changes. Port printer of an updated board: today's `41575254-4552-<epoch>-<mac>`. AppleTalk: `lw_uuid()` (W-1082). New port record on a new board: `lw_uuid()` form with the name hash replaced by the fixed tag `0001`.
- IPP paths: port record `ipp/print`; AppleTalk records `ipp/p<id>`; `ipp/laser` keeps answering for the LaserWriter migrated from W-1082.
- An AppleTalk printer is its NBP name and type; heard on two links it is one record on the preferred link: cable, network (radio), tunnel, zone.
- Every AirWriter registers `<host name>:AirWriter@*` on each link it runs; lookups skip printers registered by such a node, and its own.
- Lookups of `=:LaserWriter@*` and `=:ImageWriter@*`: at boot, every 30 s for the first 5 minutes, then every 5 minutes, and at once when the Printers section is open (and from setup's Look Again).
- A LaserWriter whose query gets no answer is asked again twice over 2 minutes, then gets the "didn't answer" notice with Try Again, Use Anyway (PostScript, Letter, 300 dpi, hex) and Remove.
- ImageWriter commands (idle CTRL-X, resync, `ESC ?` before jobs, the ImageWriter stream) go to the port only when its record's kind is ImageWriter; a ready port that does not answer `ESC ?` gets nothing more until the person says what it is.
- A different identified printer on the port is offered, never swapped: "The printer port now has an *model*. Use it instead of *name*?"
- Updated boards: records from today's NVS, nothing changes on phones; a board that never set a host name keeps `imagewriter-xxxx` (stored explicitly); new boards default to `airwriter-xxxx`.
- New boards' ways in: AppleTalk Port on, Networked Macs on, Basilisk II on, Infinite Mac off.
- On-screen words are the spec's words, verbatim (setup steps, notices, finish sheet, Remove confirmation, offline lines).
- One job at a time across the box, relayed Mac jobs included; internal RAM is Wi-Fi's: new state goes to PSRAM (`bigmem.h` / `heap_caps`), as in `docs/traps.md`.
- Board 1: checker and test pages may print without asking, daytime only; other prints wait for Wells's final sitting. Never OTA mid-print; console only via `idf.py monitor` under `script`.
- New source files carry an SPDX header (GPL-3.0-or-later for firmware and tools).

## Review Focus

1. **An updated board whose ImageWriter is off at first boot**: migration must create the port record from NVS alone, offered and shared, with no "found"/"changed" churn when the printer later answers. Test in Task 1 (`test_migrate_port_off`) and Task 5's bench step.
2. **Name collisions**: an AppleTalk printer whose NBP name equals the port printer's name, or two printers with one name: unique names, distinct Bonjour instances, stable across reboots. Test in Task 1 (`test_names_unique`).
3. **MacRoman NBP names** ("Café Laser"): UTF-8 for Bonjour, IPP and the page; the original Pascal bytes for NBP registration and lookups. Test in Task 1 (`test_macroman_name`) and Task 7 (`test_register_macroman`).
4. **A missing, short, old-version or corrupt `printers` blob**: load fails safe, migration runs only when no blob exists, legacy keys are never erased. Test in Task 1 (`test_load_garbage`).
5. **A relayed Mac job while an AirPrint job holds the box, or the target LaserWriter is busy**: the Mac is told busy (status and OpenConn), nothing deadlocks, the relay frees on either side's close. Test in Task 8 (`test_relay_busy`, `test_relay_peer_closes`).
