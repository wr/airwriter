# Rev 2026.11 board — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn rev A's main board and top case into rev 2026.11 as the design says, up to the
point where Wells draws the traces, then verify the routed board and the order package.

**Architecture:** The schematic changes through konnect. The board is updated from the
schematic in a running KiCad (konnect `update_pcb_from_schematic`). Each board edit is a
re-runnable pcbnew script in `hardware/airwriter/tools_pcb/` with KiCad closed. The top case
changes in its generator (`hardware/panel/emit_board.py`). The enclosure reads both boards, as
today. Wells routes by hand. Everything after his routing is checking.

**Tech Stack:** KiCad 10.0.6 (konnect MCP, `kicad-cli`, bundled-Python pcbnew), build123d,
Python 3.14 tests.

**Spec:** `docs/superpowers/specs/2026-10-28-rev-2026-11-board-design.md`

## Global Constraints

- **Fixed in place:** outline, H1–H4, the 37 LED and cap positions, the SW3 plunger, S1, SW1,
  J1, J2 and J4. `tools_pcb/r7_verify.py` must read 37/37 and the plunger at 0.0000 mm.
- **Antenna keepout:** x 156–162, y 127.6–154.5, both layers, no copper.
- **Fab floors:** drill ≥ 0.30 mm; track and space ≥ 0.15 mm, except the existing 0.12 mm
  `GND_STITCH_012` area. Power net class 0.5 mm.
- **File discipline:**
  - Never text-edit `.kicad_sch`, `.kicad_pcb`, `.kicad_pro`, `.kicad_sym` or `.kicad_mod`.
  - Close KiCad before a pcbnew script writes the board.
- **No autorouter.** Wells draws every new trace.
- **Commits:** at each task's end, `Refs: W-1091`. Docs in the engineering voice
  (`docs/voice-and-tone.md`).

Other schematic changes:

- **Nets:**
  - `/J4_HSKO` joins U3.7 (T2OUT) and J4.1.
  - `/J4_HSKI` joins J4.2 and U3.8 (R2IN), which comes off GND.
  - `/J4_HSKI_RX` joins U3.9 (R2OUT) and U1.19 (IO11).
  - U3.10 (T2IN) comes off GND onto `/J4_HSKO_DRV`.
- **Removed:** C7, R5, R6 and R7. R9 is no longer DNP.
- **Value changes:**
  - U3 → SP3232EBEN-L/TR (C6852).
  - U9 → SN74LV1T125DCKR (C75925).
  - R17 → 150R (C22808).
  - SW3 → TS-1002-BR15026 (C920209).
  - D3 → 3 mm green flat-top THT LED (C20613324), footprint `LED_THT:LED_D3.0mm`, with a
    Note field naming the spacer, HIWA LED4*8 (C92326).
- **Renames:** the LocalTalk nets take the Mac port's signal names:

  | From | To |
  |---|---|
  | `LT_PORT_A`, `LT_PORT_B` | `LT_PORT_RXD_N` (J4.5), `LT_PORT_RXD_P` (J4.8) |

  | `LT_Y`, `LT_Z` | `LT_TXD_N` (U6.7 B), `LT_TXD_P` (U6.6 A) |

## Review Focus

- **Schematic parity after the live update:** a footprint left on an old path or net shows as
  a parity error, not a short. Run DRC with `--schematic-parity` after task 3, not only at the
  end.
- **Old copper that now joins two nets:** the U3.8 and U3.10 GND vias-in-pad, D3's and C7's
  tracks, and J2's receive legs. Task 4 lists what it deleted, and DRC shows no shorts before
  Wells starts.
- **New parts under a lit dot's light path, or in the lattice's walls:** `r7_verify.py` and
  `enclosure/build.sh` catch both. Run them after placement, before Wells starts.
- **The top case's front copper reaching an edge, the test pad or the slash:** the panel's DRC
  and a check in `test_panel_flood.py` cover it.
- **Lite list drift:** a part added later and missed from the Lite list. `make_fab.sh`
  asserts that every Lite DNP ref exists in the AirWriter BOM.
