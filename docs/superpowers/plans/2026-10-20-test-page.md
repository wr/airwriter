# Test Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Print the approved full-page test page from all three triggers.

**Architecture:** A pure-C component `testpage` builds the page as an ImageWriter II stream
through an output callback, band by band and line by line, so the firmware and the host tests
run the same code. Bit images go through `halftone` and a shared ink-screening helper in
`ink.c`; text is escape codes. `main.c` fills in the board's details and hands the stream to
`printer_out`.

**Tech Stack:** C11, ESP-IDF 5.5, host tests in `tools/rip` (`test_util.h`), Python 3.14 with
PIL for the art generator and the preview tool.

**Spec:** `docs/superpowers/specs/2026-10-20-test-page-design.md`

## Global Constraints

- 1152 dots across (144 dpi), rows at 72 dpi, line feeds in 1/144 in; content from 0.5 in to at
  most 10.5 in below top of form.
- No text line wider than 8 in; `ESC F` values ascending within a line and under 1152.
- No `ESC K` unless the ribbon is colour; the page ends on black.
- The colour fixture and every other `make -C tools/rip regress` stream stay byte-identical.
- Copy on the page is exactly the spec's.

## Review Focus

- A host name, name or version longer than its column: cut to the column, never past 8 in.
- A second tap during the ribbon wait or mid-page: stops within one line or strip.
- Setup mode (no IP yet): the Wi-Fi line and 192.168.4.1, no "0.0.0.0".
- Unknown ribbon: the black page with the "could not tell" note.
- Each screen as the one in use: exactly one tick, beside that screen's name.

### Task 4: The page builder

**Files:** Create `firmware/components/testpage/testpage.c`, `include/testpage.h`,
`CMakeLists.txt`; Modify `tools/rip/Makefile`; Test `tools/rip/test/test_testpage.c`.

**Produces:**
```c
typedef struct {
    const char *version, *built, *model, *name, *host, *ip, *setup_ssid, *appletalk;
```

- [ ] Tests, each against a small interpreter in the test (ESC c/p/n/N/E/e/q/Q/P, ESC T, ESC F,

  dots; last printed row ≤ 10.5 in; colour ribbon sends `ESC K` 0-6 and ends on `ESC K0`;
  black and unknown send none; unknown carries "could not tell"; version, host and IP appear;
  setup mode shows "join AirWriter-2434" and "http://192.168.4.1" and no "0.0.0.0"; for each of
  the five screens exactly one `ESC & D` and it follows that screen's name; a 60-character host
  name stays inside 8 in; `stop` true after its 10th call returns `TP_STOPPED` with no FF.
- [ ] Implement as the mock-up's layout (spec section "The page").
