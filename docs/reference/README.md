# Reference documents

Two Apple publications were load-bearing for this design. They are copyrighted and not
redistributed here; both are archived in the vintage-Mac community under these titles.

- **ImageWriter II Technical Reference Manual** (Apple Computer, 1985). 227 pages. Escape codes
  (ch. 8, table 8-2 densities, p. 106; graphics bit order p. 107), "Cancel Current Line" (ch. 6),
  and the serial interface and handshake (Appendix E, pp. 204–209). Page numbers in this
  repository's docs are book pages; the common scan is image-only, PDF page = book page + 20.
- **Inside AppleTalk, Second Edition** (Sidhu, Andrews, Oppenheimer; Apple / Addison-Wesley,
  1990, ISBN 0-201-55021-0). LLAP ch. 1 and appendix B, DDP ch. 4, NBP ch. 7, ATP ch. 9,
  PAP ch. 10.
